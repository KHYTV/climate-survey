# 기후변화 인식 수업 설문

학생 설문 → 설문 종료 → **우리 반 · 한국 국민(KEI 2023) · 미국 국민(Yale)** 비교 결과를 바로 보여주는 수업용 웹.
GitHub Pages(정적 웹) + Supabase(DB)로 동작합니다.

| 화면 | 주소 | 용도 |
|---|---|---|
| 학생 설문 | `/?s=코드` | 학번·이름 입력 후 10문항(약 5분) |
| 결과 | `/results.html?s=코드` | 설문 종료 후 공개. 한 문항 = 한 페이지 슬라이드 15장(학생·프로젝터 공용) |
| 교수자 콘솔 | `/admin.html` | 세션 생성, QR, 응답 수, 종료, 명단 CSV, SASSY CSV |

**결과 슬라이드 조작**: `→`·`스페이스`·`PageDown`(프레젠터 리모컨) 다음, `←`·`PageUp` 이전, `F` 전체 화면, `Home`/`End` 처음/끝.
순서: 표지 → Q1–4(미국 비교) → 6개 유형 → Q5–10(한국 비교) → 심리적 거리 → 차이 Top 5 → 출처.
1024×768, 1280×720, 1920×1080에서 각 슬라이드가 한 화면에 들어가도록 맞췄습니다.

**배경 이미지**: ‘기후 줄무늬(Warming Stripes)’ — 1880–2025 지구 평균기온(1971–2000 대비, NASA GISTEMP v4)을
한 해 한 줄로 칠한 그림입니다(`assets/stripes.svg`). 시각화 방식: Ed Hawkins, showyourstripes.info (CC BY 4.0).

서버 없이 화면을 연습하려면 주소 끝에 `demo=1`을 붙이세요(가짜 응답 38명):
`admin.html?demo=1` · `results.html?s=DEMO&demo=1` · `?s=DEMO&demo=1`

## 1. Supabase 준비 (처음 1회, 약 10분)

1. <https://supabase.com> 로그인 → **New project**
   - Region: *Northeast Asia (Seoul)* 권장
   - Database password는 이 앱에서 쓰지 않습니다(안전한 곳에 보관만).
   - *Enable Data API*가 켜져 있어야 합니다(기본값).
2. 왼쪽 **SQL Editor** → `supabase/setup.sql` 전체 붙여넣기
   → **맨 아래 줄의 `여기에-비밀번호`를 본인만 아는 관리자 비밀번호(12자 이상)로 바꾼 뒤** Run.
   (비밀번호를 바꿀 때도 같은 방법으로 다시 실행하면 됩니다.)
3. **Project Settings → API Keys**(또는 상단 *Connect*)에서
   - Project URL → `assets/config.js`의 `SUPABASE_URL`
   - **publishable key**(`sb_publishable_...`, 또는 legacy *anon* key) → `SUPABASE_KEY`
   - ⚠️ `secret` / `service_role` 키는 절대 넣지 마세요. publishable 키는 공개용이며, DB는 표 직접 접근이 막혀 있고 정해진 함수로만 동작합니다.
4. 무료 플랜은 7일간 사용이 없으면 일시정지됩니다. **수업 전날 콘솔에 한 번 접속**해 확인하세요.

## 2. 리허설 (수업 전)

1. `admin.html` → 관리자 비밀번호로 접속 → 테스트 세션 만들기
2. 휴대폰으로 QR 참여 → 제출 → 콘솔 응답 수 확인
3. **설문 종료하기** → 결과 화면 확인(응답 5명 미만이면 결과가 숨겨지므로 5명 이상 테스트)
4. **SASSY 분류용 CSV** → [Yale SASSY 페이지](https://climatecommunication.yale.edu/visualizations-data/sassy/)의 그룹 툴에 업로드 → 결과 CSV를 결과 화면 ②에서 불러오기
   - Yale 툴이 요구하는 형식(열 이름 `casenumber, important, worry, personal, future`, 영어 원문 응답)으로 만들어집니다. **실제 업로드가 되는지 꼭 리허설에서 확인하세요.**
5. 테스트 세션 **삭제** → 수업용 세션은 수업 당일 새로 만들기

## 3. 수업 진행 예시 (60분)

| 시간 | 할 일 |
|---|---|
| 0–5분 | 콘솔에서 세션 만들기 → **QR 크게 띄우기** |
| 5–15분 | 학생 응답(약 5분). 콘솔의 응답 수가 수강 인원에 가까워지면 |
| 15분 | **설문 종료하기** → **결과 화면 열기** (학생 휴대폰에도 ‘결과 보기’ 버튼이 자동으로 나타남) |
| 15–20분 | (선택) SASSY CSV → Yale 툴 → 결과 CSV 불러오기 → ② 6개 유형 |
| 20–55분 | 요약(심리적 거리, 차이 큰 항목) → ① 미국 비교 → ② 6개 유형 → ③ 한국 비교 순으로 설명·토론 |
| 수업 후 | **참여자 명단 CSV** → 참여 점수 부여 · **응답 원자료 CSV** + **코드북** 보관 |

### 통계분석용 원자료

- 콘솔의 **응답 원자료 CSV**: 응답자 1명 = 1행, 36열(UTF-8, 엑셀·SPSS·R에서 바로 열림). 파일 이름 `원자료_설문일_코드.csv`.
  - `id` = 설문일(세션 생성일) + 순번, 예: `20261006-001` — 이름·학번과 연결되지 않는 익명 ID
  - `resp_no` = 순번(같은 세션의 SASSY CSV `casenumber`와 같은 번호 → Yale 툴의 6개 유형 결과를 이 번호로 합칠 수 있음)
  - `session` = 참여 코드(여러 반 파일을 합칠 때 구분)
  - 단일선택 문항은 숫자 코드, ‘3개 선택’ 문항은 보기별 0/1 더미 변수(`emo_*`, `img_*`)
  - SASSY `personal`·`future`의 0은 ‘모르겠다’ — 분석 시 결측 처리 여부를 정하세요.
- **코드북**: 변수 이름, 문항 원문, 값의 뜻.
- 같은 날 여러 반을 조사하면 `id`가 겹칠 수 있으니 `session`과 함께 쓰세요.
- 연구(학회 발표·논문)에 쓸 계획이면 IRB 승인과 학생 동의 절차를 먼저 확인하세요.

## 4. 개인정보 처리

- 이름·학번(`cs_participants`)과 답변(`cs_responses`)은 **연결 키 없이 따로** 저장되고, 답변 표에는 제출 시각도 없습니다.
- 결과 화면, 원자료 CSV, SASSY CSV에는 이름·학번이 없습니다. 명단은 관리자 비밀번호로만 받을 수 있습니다.
- 응답이 5명 미만이면 결과를 표시하지 않습니다(`assets/config.js`의 `MIN_N`).
- 학기 종료 후 콘솔의 **세션 삭제**로 명단·응답을 함께 지울 수 있습니다(되돌릴 수 없음).

## 5. 문항과 비교 기준

- **A. Yale SASSY 4문항**(Chryst et al., 2018): 개인적 중요성, 걱정, 나에 대한 피해, 미래 세대 피해. 한국어 번역은 이 앱에서 만든 것입니다.
- **B. KEI 국민환경의식조사 2023 문항**(발표자료 「우리국민의 기후변화인식: 현황과 진단」에서 재구성):
  기후변화 중요성, 대상별 피해 8개, 감정(3개 선택), 떠오르는 것(3개 선택), 미디어의 심각성 묘사, 환경 vs 편리.
- 기준값은 `assets/items.js`에 있습니다.
  - 한국: KEI 2023, 만 19–69세, N=3,088 (가중)
  - 미국 문항: Climate Change in the American Mind, 2025년 11월, N=1,146
  - 미국 6개 유형: Global Warming’s Six Americas, 2025년 5월 (26/27/19/7/11/11%)

### 해석 시 주의
- 학생 응답은 수업 참여자만의 결과로 대표성이 없습니다.
- SASSY는 미국 영어로 검증된 도구입니다. 한국어 번역본의 6개 유형 결과는 탐색적으로 해석하세요.
- 한국·미국 조사는 문구와 척도가 달라 서로 간 비교는 경향 수준입니다. 그래서 각 비교는 **같은 문항끼리만** 묶었습니다(SASSY↔미국, KEI↔한국).
- KEI 문항의 정확한 원문·보기는 발표자료에서 추정한 부분이 있습니다(예: 감정·이미지는 합계가 300%라 ‘3개 선택’으로 판단).
